# SisaRasa — Landing Page

Landing page SisaRasa, marketplace makanan surplus untuk mahasiswa di sekitar kampus Undip Tembalang, Semarang.

- Situs: https://abrarmf.github.io/sisarasa/
- Dibangun dengan HTML/CSS/JS murni (satu file `index.html`), dihosting di GitHub Pages.
- Formulir "Daftar beta" mengirim data ke Google Form; analytics memakai Google Analytics 4.
